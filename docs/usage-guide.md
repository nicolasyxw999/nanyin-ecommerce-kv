# 使用指南

## 1. 选择本次任务

| 需要什么 | 怎么开始 | 交付 |
|---|---|---|
| 尚无明确设计方向 | 上传产品图或填写资料，要求自动推荐 | 信息整理、风格建议、逐张构图规划 |
| 只要提示词 | 明确“只输出提示词，不生图” | 同编号的两套独立语言文件 |
| 看第一张效果 | 认可方向后要求“先生成第1张” | 一张独立原图与实际路径 |
| 整套连续生成 | 明确“全部生成，不用逐张确认” | 按编号保存的各张原图与交付清单 |
| 修改已有成图 | 附上目标图片，说明只改哪里 | 保留原文件的修订版本 |

安装技能不代表已授权发布；只生成提示词时不会启动生图。新产品资料较少可先从已有卖点做起，不需要为了开工补造参数。

## 2. Codex 调用

完整安装目录应包含 `SKILL.md`。使用 `$nanyin-ecommerce-kv` 加上产品资料调用；也可以用自然语言说明要制作电商KV。未被当前会话发现时开启新会话，或明确给出技能文件位置。

推荐先发：

```text
$nanyin-ecommerce-kv
品牌：青禾。产品：日常随行杯。
真实卖点：自然语言设置饮水偏好、每周回看记录、可选日历提醒。
目标人群：办公和居家工作人群。
附上产品参考图。请保持产品结构和LOGO位置。
需要10张9:16海报，画面中文。
先给构图规划与纯中文、纯英文两套独立提示词，不生图。
```

“青禾”仅为输入方式的虚构示例，不代表真实商品或性能。交付客户时替换为自己的资料，成图不会印上这类示例说明。

## 3. Claude 使用

在支持自定义技能的环境中，将完整技能按该环境的安装或上传方式载入，再提供产品资料。没有技能导入入口时，直接粘贴独立模板并填入本次资料。若使用 Claude Code 的本地技能目录，按当前版本所提供的技能发现机制安装，不把 Codex 的目录和命令直接当作所有 Claude 产品的通用安装方式。

Claude 是否可直接生成或编辑图片取决于其实际连接的工具。仅有文字能力时，技能完成规划、文案与提示词交付；有可用生图工具时，智能体再依照真实工具说明逐张执行。无工具时不声称已出图。

## 4. Lavart 使用

先附上产品参考图，再粘贴一张已经填好的单语言提示词。系列任务逐张绑定同一产品参考，明确“参考锁定外观，不照抄首张构图”。若当前环境支持智能体连续执行，使用 `references/agent-zh.txt` 或 `references/agent-en.txt` 加上全部编号提示词。

本指南提供可迁移的自然语言指令，不承诺 Lavart 具有某个固定按钮、导入格式、接口或自动化开关。没有批量能力时保留单张可粘贴方式。

## 5. 语言怎么选

**提示词语言**是发给模型的指令语言；**画面文字语言**是消费者在海报上看到的文案。两者独立。

- 要求两套提示词时，分别保存 `prompts-zh.md` 与 `prompts-en.md`，不要交错混排。
- 中文套全部使用中文指令，英文套全部使用英文指令。品牌固有拼写与色值按实际保留。
- 两套应使用相同编号、相同创意与对应信息；选其中一套执行即可，不会因为两种语言就重复生成两批图片。
- 英文提示词也可以要求中文成图。需要精确固定另一语言的文案时，另附语言独立的文案表，在执行时读取。
- 模板里的方括号是填写槽位，填好后再粘贴到图像工具；交付成品提示词时不应留下空槽位。

## 6. 统一外观，改变构图

产品结构、比例、材质表现、LOGO位置、品牌色和字体体系保持一致。各张的主体、景别、视角、占比、阅读路线和文字区按信息任务设计。10张建议覆盖主视觉、使用场景、逻辑说明、交互、微距、记录回顾、会议间隙、品牌情绪板、真实规格或功能概览、使用指南等不同任务。

图像模型可能改变结构或文字。每张检查外观、文案和尺寸；发现明确问题时只修相关张，不把联系表当成完整套图。无法确认的检查记录在交付说明中，不印进海报。

## 7. 信息不全与电商图规则

- 未提供容量、材质牌号、续航或保温小时，就省略它们；没有足够真实规格时把规格页改为功能概览。
- 不把“待确认”“不确定”“样例数字”等内部标签带入成图，不用虚构数值填空。
- 不伪造认证、销量、评价、医生背书或检测报告。
- 海报外层不用可点击按钮、跳转箭头、导航和伪链接；手机屏幕内可展示产品真实功能所需控件。
- 免责声明遵循本次项目约定；不要把某个案例的页脚套到其他品牌。
- “南殷居士”“南殷用AI”是技能维护者属性，不会自动作为客户品牌、水印或推广语进入商品图。

## 8. 自动化执行与断点续作

批量授权后先清点已有文件、绑定产品参考和编号方案，再逐张出图。保存实际返回的文件，检查后记录结果。有明确问题的单张最多修复两次；仍失败则记录该张，继续其他独立张。中断后先读取交付清单，只补缺失项。

建议输出：

```text
项目目录/
  prompts-zh.md
  prompts-en.md
  composition-plan.md
  images/
    poster-01.png
    poster-02.png
  delivery-report.md
```

文件名为建议，实际按用户指定目录与工具输出调整。报告记录编号、主题、实际输出路径、读取到的像素及检查结果。未执行的检查如实说明，不把文件存在等同于完整质量验证。
